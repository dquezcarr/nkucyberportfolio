# Security Architecture – System Design & Risk Analysis Investigations

## Overview

This course focused on designing secure systems through threat modeling, risk analysis, and architectural decision-making. The investigations below demonstrate how security is integrated into system design, including data flows, access control, vulnerability management, and compliance-driven assessments.

---

## Security Investigations

### Threat Modeling Investigation: Risk Identification & STRIDE-Based Analysis

* **Objective:** Identify threats, vulnerabilities, and risks within system components

* **Skills:** Threat modeling, STRIDE analysis, risk identification

* **Key Findings:**

  * Identified multiple high-risk threats including spoofing, data tampering, and denial of service
  * Mapped threats across system processes and data flows
  * Highlighted lack of mitigation controls for critical vulnerabilities 

---

### Access Control Investigation: Threat-Agent to Control Mapping

* **Objective:** Map threat agents to vulnerabilities, risks, and security controls

* **Skills:** Risk modeling, control design, security patterns

* **Key Findings:**

  * Identified risks such as unauthorized access due to lack of MFA and access controls
  * Implemented mitigation strategies including RBAC, encryption, and firewalls
  * Applied security design patterns like Authenticator and Firewall models 

---

### Data Flow Investigation: System Interaction & PCI Risk Analysis

* **Objective:** Analyze data flow and process flow within an application system

* **Skills:** Data flow mapping, process modeling, compliance awareness

* **Key Findings:**

  * Modeled full transaction lifecycle from user input to system output
  * Identified sensitive data handling risks during payment processing
  * Highlighted PCI compliance considerations for handling credit card data 

---

### Threat Framework Investigation: STRIDE, PASTA, LINDDUN Comparative Analysis

* **Objective:** Evaluate and compare multiple threat modeling frameworks

* **Skills:** Framework analysis, threat classification, security methodology

* **Key Findings:**

  * Compared frameworks across lifecycle, inputs, outputs, and use cases
  * Identified STRIDE for early-stage design and PASTA for enterprise-level analysis
  * Highlighted LINDDUN’s focus on privacy threats and CVSS for vulnerability scoring 

---

### System Architecture Investigation: Trust Boundaries & Attack Surface Mapping

* **Objective:** Analyze system architecture for vulnerabilities and attack paths

* **Skills:** Architecture design, trust boundaries, vulnerability mapping

* **Key Findings:**

  * Identified critical attack surfaces including APIs and database communication
  * Defined trust boundaries between front-end, services, and databases
  * Applied OWASP, CWE, and CVE frameworks for vulnerability mapping 

---

### Security Control Investigation: Access Control Models & Cryptographic Protection

* **Objective:** Evaluate security mechanisms and assurance strategies

* **Skills:** Access control (MAC, DAC, RBAC, ABAC), encryption, hashing

* **Key Findings:**

  * Compared access control models based on flexibility, scalability, and security
  * Demonstrated how encryption + hashing ensures confidentiality, integrity, and non-repudiation
  * Evaluated firewall strategies including whitelisting vs blacklisting 

---

### Security Assessment Investigation: CSET-Based Risk & Compliance Analysis

* **Objective:** Perform structured security assessments using industry tools

* **Tools:** CSET (Cyber Security Evaluation Tool)

* **Skills:** Risk assessment, compliance analysis, reporting

* **Key Findings:**

  * Conducted CMMC Level 5 assessment for cybersecurity maturity 
  * Achieved 100% compliance across multiple security domains in RRA analysis 
  * Generated site-level security reports including system posture and recommendations 

---

### Security Usability Investigation: Balancing User Experience & Security Controls

* **Objective:** Evaluate tradeoffs between usability and security mechanisms

* **Skills:** Security usability modeling, human risk analysis

* **Key Findings:**

  * Identified user behaviors that weaken security (e.g., bypassing controls due to friction)
  * Analyzed risks such as session hijacking, weak passwords, and insecure data storage
  * Proposed balanced solutions using secure defaults and user-friendly controls 

---

## Key Skills Developed

* Data flow and process flow modeling
* Access control and cryptographic security design
